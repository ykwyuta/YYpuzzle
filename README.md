# はじけるのがみえる あわパズル

スマホで遊べる、**はじめてでも れんさ が できる** おちものパズルです。
上から ふってくる 2つぐみの **あわ** を つみあげて、おなじ いろを たて・よこに 4つ つなげると ぱちんと はじけます。
置く前に「置いたら どの あわが はじけるか」「なんれんさ に なるか」が ひかって 見えるので、遊びながら れんさ の しくみを 覚えられます。

[ひっくりかえるのがみえるリバーシ（YYreversi）](https://github.com/ykwyuta/YYreversi) と同じ考え方・同じ構成で作っています。ブラウザだけで動く静的サイトです。ビルドもサーバーも要りません。Cloudflare（Workers の静的アセット配信）でそのまま公開できます。

- **たいせん**：くだもの・やさいの キャラクター 8人と しょうぶ（★1 いちご 〜 ★8 かぼちゃ の だいおう）
- **にじあわ** と **フルーツパワー**：どの いろとも つながる にじいろの あわ と、キャラクター ごとに ちがう とくべつな わざ（くわしくは 下の「ルール」）
- **ひとりで**：じぶんの ペースで れんしゅう（3しょく・4しょく・5しょく。「まった」で 何回でも もどせる）
- おちる はやさ：ゆっくり・ふつう・はやい
- 勝った あいてには ✓ が付き、さいこう きろく と いっしょに 自動保存
- ホーム画面に追加すると アプリのように 全画面で使えます

---

## みた目

- あわには かおが あって、まばたき したり、はじける まえに にっこり したり、まんなかが つまると こまった かおに なります（「せってい」で かお なしにも できます）。
- おちると ぷるんと つぶれて もどり、はじけると しろく ひかって ちいさな あわと ほしが とびちります。
- れんさ すると「2れんさ！」の もじが ほしがたの ひかりと いっしょに とびだし、おおきな れんさ では ばめんが ゆれます。
- たいせんの はじめには「VS」がめん。かつと くるくる まわる ひかりの「かち！」。

## 子ども向けの おたすけ機能

| 機能 | 内容 |
| --- | --- |
| おちる ばしょ | いま おとすと どこに つくかを、うすい あわ で表示。 |
| はじける よそう | そこに置くと はじける あわが ぴかぴか ひかり、「ここに おくと 2れんさ に なるよ！」と 教えてくれる。 |
| つながり | となりあう おなじ いろの あわは くっついて 見える。あと いくつで はじけるか 分かる。 |
| マーク | あわに ハート・はっぱ・しずく・ほし・ダイヤ の しるし（いろが 分かりにくい人にも）。 |
| まけの しるし | ふたつぐみが 出てくる ところに ✕。まんなかが たかくなると ✕ が ひかって 知らせる。 |
| ヒント | CPU が おすすめの ばしょを てんせんで 教えてくれる。 |
| まった | ひとりで あそぶ ときは、置いた あわを 何回でも もどせる。つまって おわった あとでも もどれる。 |
| とめる | いつでも いったん とめられる。ほかの アプリに うつったときは 自動で とまる。 |

「ルール」ボタンでは、4つで はじける・ななめは つながらない・れんさ・くもりあわ・はねかえす・まけ・ぜんぶ けすと ボーナス・うえに はみだすと を 図つきで 説明します。

## ルール

- 2つぐみの あわが 上から おちてくる。左右に うごかしたり まわしたり して おく。2つが はなれて おちることもある。
- おなじ いろの あわが たて・よこに 4つ いじょう つながると はじける。はじけて あいた ところに 上の あわが おちて、また つながれば **れんさ**。
- 見える ところより 上（みえない 1だん）に のこった あわは、ふわっと とんでいって きえる。
- 左から 3れつめ の いちばん 上（✕）まで つまったら まけ。
- ばめんの あわを ぜんぶ けすと ボーナス。

### にじあわ

- 4くみめ から ときどき（7% くらい）、ふたつぐみの かたほうが **にじあわ** に なる。ふたりとも おなじ じゅんばんで くる。
- にじあわ は となりあう どの いろの なかまにも なる。2つの いろの あいだに おくと、りょうほうの かたまりに はいって いっしょに はじけさせる ことも できる。
- にじあわ だけ では はじけない。

### フルーツパワー

あわを はじけさせると（くもりあわ は のぞく）パワーが たまり、24こ で いっぱい。「パワー」ボタン（キーボードは Enter か S）で、えらんだ キャラクターの わざ が でる。おちている ふたつぐみは いったん もどり、わざの あとに もういちど でてくる。わざで はじけた あわも れんさ・てんすう・くもりあわ に なる。

| キャラクター | わざ | こうか |
| --- | --- | --- |
| いちご | いちごジャム | くもりあわ が ぜんぶ あかい あわ に かわる |
| にんじん | にんじんドリル | いちばん ながい れつ の あわを ぜんぶ けす |
| トマト | トマトスプラッシュ | いちばん おおい いろ の あわが（はなれていても）ぜんぶ はじける |
| バナナ | バナナにじ | つぎの 2くみ が にじあわ 2こ に なる |
| なす | なすの おまじない | つぎの 3くみ が おなじ いろ どうし の ふたつぐみ に なる |
| ブロッコリー | もりもりバリア | くもりあわ を ぜんぶ けして、とどく まえの くもりあわ も けす |
| ぶどう | ぶどうの ふさ | いちばん すくない いろ の あわが、となりに いちばん おおい いろ に そまる |
| かぼちゃ | パンプキンボム | でてくる れつ と その りょうどなり を、うえから 5こ ずつ ふきとばす |

CPU も パワーが たまると、やくに たつ ときに つかってくる（たとえば いちご は くもりあわが 4こ いじょう あるとき）。

### たいせん

- はじけさせると あいての ばめんに **くもりあわ**（はじけない あわ）が ふっていく。てんすう 60 で 1こ。
- くもりあわは、となりで あわが はじけると いっしょに きえる。
- くもりあわが とどく 前に じぶんも はじけさせると、とどく かずを へらせる（はねかえす）。のこりは あいてへ。
- くもりあわは、じぶんが あわを おいて れんさ が おきなかった ときに ふってくる（1回に 30こ＝5だん まで）。
- ふたりとも おなじ じゅんばんで おなじ いろの あわが くる（こうへい）。

### てんすう

1回 はじけるごとに `10 × きえた かず × ばいりつ`（ばいりつは さいてい 1）。

- れんさ：1れんさめ 0、2れんさめ 4、3れんさめ 8 …（1つ ふえるごとに +4）
- 5こ いじょう つなげた：1こ ふえるごとに +1（さいだい +10）
- 2しょく いじょう どうじ：1しょく ふえるごとに +3

たとえば 4こずつの 2れんさ は 40 + 160 = 200てん（くもりあわ 3こ）、3れんさ は 520てん（8こ）、4れんさ は 1000てん（16こ）、5れんさ は 1640てん（27こ）。

## Cloudflare で無料公開する

Cloudflare Workers の静的アセット配信を使います。ビルドは不要です。設定はリポジトリに入っている `wrangler.jsonc` / `.assetsignore` / `_headers` だけです。

### 方法 A：GitHub と連携して自動デプロイ（おすすめ）

1. ゲーム本体と `wrangler.jsonc` が入ったブランチを、Cloudflare がビルドする本番ブランチにしておく（このリポジトリの既定ブランチは `master`）。
2. [Cloudflare ダッシュボード](https://dash.cloudflare.com/) → **Workers & Pages** → **作成（Create）** → **リポジトリをインポート（Import a repository）**。
3. GitHub を連携して `YYpuzzle` を選ぶ。
4. 設定はそのまま（ビルドコマンド：空欄、デプロイコマンド：`npx wrangler deploy`、ルートディレクトリ：`/`）。
5. **デプロイ** を押すと `https://yypuzzle.<あなたのサブドメイン>.workers.dev` で公開されます。

### 方法 B：手元のパソコンからコマンドで公開

```sh
npx wrangler login    # 初回のみ
npx wrangler deploy   # 公開（URL が表示される）
```

手元で確認したいときは `npx wrangler dev`（または `python3 -m http.server`）で立ち上げます。

## 操作

がめん（ばめんの あたり）を タップして うごかします。

| | がめんを タップ | ボタン | キーボード |
| --- | --- | --- | --- |
| ひだりへ | ひだりがわ 3ぶんの1（おしたままで れんぞく） | ◀ | ← |
| みぎへ | みぎがわ 3ぶんの1（おしたままで れんぞく） | ▶ | → |
| まわす | まんなか | ⟳ | ↑ / X / Z |
| すとんと おとす | したの 4ぶんの1 | ⤓ | スペース |
| はやく おとす | | ▼（おしている あいだ） | ↓ |
| フルーツパワー | | パワー | Enter / S |
| とめる | | 「とめる」 | P / Esc |

まわす むきは 1つ（みぎまわり）だけ です。
かべや あわの そばで まわすと、はんたいがわに ずれて まわります。左右が ふさがった 1れつの すきまでは、上と下が いれかわります。

## ファイル構成

```
index.html             画面
css/style.css          見た目（スマホ縦向きを基本に、広い画面でも 中央に）
js/rules.js            ルールエンジン（うごく・まわす・おく・はじける・れんさ・てんすう・くもりあわ・まけ）
js/ai.js               CPU の かんがえ（おける ところを ぜんぶ ためして ひょうか。つよい CPU は つぎ まで よむ）
js/worker.js           CPU の かんがえを Web Worker で動かす（画面が固まらない）
js/chars.js            くだもの・やさいの キャラクター（SVG の え・ひょうじょう・セリフ・つよさ）
js/ui.js               描画（canvas）と操作・アニメーション・おと・保存
manifest.webmanifest   ホーム画面に追加したときの設定
icons/                 アイコン
test/                  Node.js で動くテスト（公開はされない）
tools/                 アイコン作成ツール（公開はされない）
```

ルールエンジンは DOM に依存しない純粋な関数で、盤（`Int8Array`）を受け取って 常に新しい盤を返します。`resolve` は れんさ を1だんずつ `steps` として返すので、画面はそれを順番に アニメーションするだけです。ふたつぐみの じゅんばんは たね（seed）から決まり、ふたりに 同じ じゅんばんで 配られます。

```js
require('./js/rules.js'); require('./js/ai.js');
const E = Engine;
const f = E.parse(['R.....', 'B.....', 'B.....', 'B.....', 'BRRR..', 'GYYY..']);
const r = E.resolve(f);
console.log(r.chain, r.points);           // 2 200
const q = E.makeQueue(42, 4);
console.log(AI.choose(E.newField(), [q.at(0), q.at(1)], AI.LEVELS[8], { colors: q.colors }));
```
